# Hardware Components

## Main Components

### Arduino Uno
Acts as the main processing unit. It reads the analog signals generated by the piezoelectric sensors.

### Piezoelectric Sensors
Five piezoelectric discs are used to detect vibrations caused by an impact.

### 1N4148 Diodes
Used in the sensor signal-conditioning circuit.

### Zener Diodes
Used for voltage protection and signal limiting.

### 1 MΩ Resistors
Provide a discharge path and help define the sensor signal behavior.

### 0.1 µF Capacitors
Used for signal conditioning and filtering.

### Breadboard
Used for prototyping and connecting the sensor-conditioning circuits.

### Jumper Wires
Used to connect the sensors, conditioning circuits and Arduino.

### Impact Plate
Provides the physical surface on which the strike is applied.
